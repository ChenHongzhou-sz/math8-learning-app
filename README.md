# 八上数学互动学习 App

面向 iPad 的八年级上册数学互动学习 Web App。当前覆盖第十一章“三角形”和第十二章“全等三角形”，包含学习地图、互动几何、即时练习、家长提示和本地进度。

当前界面采用清爽蓝天色系，并把学习地图和家长驾驶舱默认收窄到两侧，让中间学习区更宽。第十一章和第十二章练习已统一为“图形优先”的练习卡，先看图再选择答案；每节观察页都提供可选 GeoGebra 实验板入口。

## 部署

这是纯静态项目，可部署到 GitHub Pages。仓库启用 Pages 的 GitHub Actions 来源后，`.github/workflows/pages.yml` 会发布根目录。

## Supabase

默认使用浏览器本地进度。若要跨设备同步：

1. 在 Supabase 新建项目。
2. 在 SQL Editor 执行 `supabase/schema.sql`。
3. 在 `config.js` 中填入 `supabaseUrl` 和 `supabaseAnonKey`。

`anon public key` 可以放在前端；不要把 `service_role` key 放进仓库或网页。

日常更新课程内容、题目、动画和界面样式时，通常不需要修改 Supabase；只有新增需要云端保存的数据字段或表结构时，才需要更新 `supabase/schema.sql`。
